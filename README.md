## 国内访问体验：没有 CN2 GIA，晚高峰要自己测

RackNerd 官方没有宣传任何回国优化线路。洛杉矶走的是 Cogent、Arelion、Lumen 这类普通国际线路，不是 CN2 GIA，也不是 AS9929。

实际能期待什么：白天国内 ping 大概 150 到 200 ms，打开后台、传文件都还算顺手。国内晚上 8 点到 11 点这段时间，公网出口拥堵，延迟和丢包会有明显波动，电信用户感受通常比联通移动更差。拿它放面向国内读者的站，访客体验会受影响；放面向海外用户的站、或者自己用的后台和工具，问题不大。

还有个容易被误读的参数：所有套餐写的 1 Gbps 是端口规格，指这台机器接的是千兆口，不代表从中国大陆下载能跑到 1 Gbps。

官方公开的测试 IP：

| 机房 | 测试 IP | 上游线路 |
| --- | --- | --- |
| 洛杉矶 DC-03 | `107.174.51.158` | Cogent、Arelion、Lumen |
| 西雅图 | `192.3.253.2` | Cogent、Telia |
| 纽约 | `192.3.81.8` | Cogent、Arelion、GTT |
| 达拉斯 | `198.23.249.100` | TeliaSonera、XO |

测法很简单：白天在你常用的网络下 ping 一次，晚上 9 点再 ping 一次，两次差别很大就说明你这条线路晚高峰不行。想看得细一点，用 mtr 跑几十个包，看回程在哪一跳开始丢。四个 IP 都测一遍再决定机房，别默认洛杉矶一定最快，各地运营商路由不一样。
